# 14:45 持仓卖出规则 V1

适用范围：加密交易台账中全部实际持仓。尾盘消息必须同时给出新买入判断和持仓卖出判断；持仓扫描失败时，禁止把缺失结果解释为“继续持有”。

系统输出的是明确的执行建议和数量，不直接连接券商账户自动成交；实际成交后仍需回填交易台账。

## 优先级

1. **结构破位（风险退出）**：连续两根 5 分钟K线收盘低于结构止损参考，且 14:45 当前价仍低于该线，输出 `EXIT_ALL`，卖出当日可卖数量。
2. **盈利回撤（分批锁利）**：只有入场后最高收盘价相对成本达到 `+8%`，回撤机制才激活；随后相对最高收盘价回撤达到 `5%`，输出 `REDUCE_50`，按100股整数单位卖出约一半。
3. **其他情况**：输出 `HOLD`。当日买入、受 T+1 限制的数量输出 `HOLD_T1`，但仍显示结构风险。

若结构破位和盈利回撤同时出现，以 `EXIT_ALL` 为准。这里的“回落5%”是相对入场后的最高收盘价，不是相对买入成本亏损5%，也不采用单笔瞬时最高价，避免一根上影线造成误卖。

## 结构止损参考

- 初始使用该笔推荐在买入时保存的结构止损位。
- 当最高浮盈达到 `+5%` 后，结构线只上移不下移：取原始结构止损与上一完整交易日 MA10 的较高值。
- 板块退潮可以作为风险提示，但 V1 不允许仅凭板块弱就强制卖出个股；必须由个股结构或已激活的盈利回撤规则触发。

## 隐私与审计

实际账户、持仓数量、成本和卖出建议不写入明文文件。尾盘运行只向 PushPlus 展示，并使用 `TRADING_DATA_KEY` 加密保存决策审计文件。

V1 阈值后续应使用历史真实交易做参数组回测（激活点 6%/8%/10%，回撤 4%/5%/6%），再依据期望收益、最大回撤和过早卖出比例决定是否调整，不能只用单日案例修改。
