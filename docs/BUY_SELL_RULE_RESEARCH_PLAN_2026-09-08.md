# 强势股二次启动：买入与卖出规则研究计划（2026-09-08）

## 1. 结论先行

买入和卖出都采用“结构为主、量价确认、市场与板块修正”的叠加方式，不采用单一价格阈值。

- 买入：只有二次启动结构已经形成，才讨论尾盘量价、换手、量比与板块共振；任何单项放量或上涨都不能单独触发买入。
- 卖出：结构破位负责控制风险，盈利回撤负责锁定已有利润；两者不是二选一。量价、换手和板块用于判断破位或回撤的可信度与紧迫度。
- OpenAI：负责解释证据和处理冲突，不负责创造行情事实，也不能绕过程序硬门禁。
- 所有阈值先作为研究参数。只有完成时间顺序回测、样本外验证和真实尾盘验收后，才可升级为正式规则。

## 2. 买入规则分层

| 层级 | 必须观察的事实 | 规则职责 | 不允许的用法 |
|---|---|---|---|
| 生命周期 | 前期强势、120/250日趋势、距长期高低点、主升/整理/衰退状态 | 排除长期下降中的普通反弹 | 不能把“接近250日高点”机械等同于强势 |
| 整理结构 | 平台持续时间、振幅收敛、稳健上沿、MA5/MA10止跌、结构止损 | 确认第一次上涨后确有整理且尚未破坏 | 不能仅凭一天上涨认定二次启动 |
| 流动性 | 成交量收敛与换手率收敛合并证据、成交额可交易性 | 识别整理期筹码沉淀和基本可交易性 | 成交量与换手率高度相关，不能重复计两票 |
| 14:40–14:45触发 | 当前价、约30分钟涨幅、实时量比、尾盘量能加速、换手率、5分钟量价 | 判断是否正在从平台再次启动 | 不能只按机械确认分下单 |
| 市场与板块 | 大盘适宜度、同期行业/概念强弱、资金与退潮状态 | 调整仓位和确认可信度 | 未核验或退潮不得伪装成“板块共振” |
| 风险收益 | 买入区间、结构止损、到止损的风险距离、总仓位上限、T+1 | 形成可执行建议 | 买入区间和止损缺一不可 |

### 2.1 研究中的候选买入门禁

候选规则按以下顺序执行：

1. 二次启动结构与生命周期通过；
2. 振幅、流动性收敛、短期止跌三类中至少两类有支持，且关键数据缺失必须明示；
3. 14:45价格未明显远离平台上沿，避免追高；
4. 5分钟价格改善与量能改善相互确认；实时量比和换手率用于区分有效启动、无量拉升和过度爆量；
5. 大盘不适宜时降低总仓位或不交易；板块退潮仍是正式观察池/买入端的风险门禁，板块未核验不得写成共振；
6. 仅在风险距离、T+1和组合仓位均可接受时输出 `TRADE`，否则输出 `WAIT/REJECT`。

## 3. 卖出规则分层

### 3.1 正式 V1 保留规则

在增强规则完成验证前，继续保留当前安全规则：

- 连续两根5分钟K线收盘低于结构止损，且当前价仍低于该线：`EXIT_ALL`；
- 入场后最高收盘浮盈达到8%，随后相对最高收盘回撤达到5%：`REDUCE_50`；
- 两个条件同时出现时，结构破位优先；
- 数据缺失输出 `DATA_ERROR`，不得解释成继续持有；当日新增仓位遵守 T+1。

### 3.2 待回测的 V2 多因子增强

| 场景 | 价格/形态 | 量价、换手与量比 | 候选动作 |
|---|---|---|---|
| 正常缩量回踩 | 未破结构线或很快收回 | 回踩缩量、换手回落、无尾盘放量杀跌 | `HOLD`，避免被普通洗盘误伤 |
| 确认破位 | 连续收于结构线下 | 放量下跌、换手放大或尾盘量能加速向下 | `EXIT_ALL`，量能增强破位可信度 |
| 无量破位 | 连续收于结构线下 | 成交量未放大 | 风险线仍优先退出；单独记录为“无量破位”，回测其误杀率 |
| 冲高回撤 | 已有显著浮盈，距最高收盘回撤达到参数阈值 | 高位放量滞涨、长上影或换手异常放大 | `REDUCE_50`，锁定一部分利润 |
| 健康换手上行 | 回撤未达阈值、平台上沿未失守 | 量价配合、换手不过热、板块未退潮 | `HOLD`，让利润继续运行 |
| 启动失败 | 买入后若干交易日仍未突破，跌回平台 | 量能持续衰减或资金/板块同步转弱 | 研究时间止损或减仓，不直接上线 |

结构破位不能因为“没有放量”而被否决，因为价格已经越过预先定义的失效线；量能证据主要用于衡量破位可信度、分析误杀，并研究是否需要更早减仓。盈利回撤则必须在利润保护已激活后才使用，避免普通波动触发机械卖出。

## 4. 回测设计

### 4.1 防止未来数据泄漏

- 买入判断只能使用14:45以前已经产生的数据；正式收盘价只能用于事后评价。
- 板块归因只使用当日或此前已保存的快照，不能用今天的板块分类倒推历史。
- 参数按交易时间顺序切分：训练段、验证段、最终样本外段；不随机打乱。
- 同一股票相邻持仓周期不得跨训练集和样本外集合传播未来信息。

### 4.2 参数网格

| 参数组 | 首轮研究值 |
|---|---|
| 盈利回撤激活 | 最高收盘浮盈 6% / 8% / 10% |
| 从高点回撤 | 4% / 5% / 6% |
| 结构参考 | 原始止损 / MA10上移 / 平台低点上移 |
| 破位确认 | 1根 / 2根5分钟收盘；收盘日线确认作为对照 |
| 量能确认 | 相对近3根、近5日、近20日的成交量倍率 |
| 活跃度 | 换手率绝对分位、相对自身20日分位、异常放大倍率 |
| 实时量比 | 低量、正常、显著放量、极端放量分箱，不先假设线性关系 |
| 时间止损 | D+3 / D+5 / D+10未启动，仅作研究对照 |

### 4.3 验收指标

- 单笔期望、胜率、盈亏比、Profit Factor、最大回撤；
- 平均持有天数、年化换手、资金占用；
- 曾达到 +5% 后最终亏损的利润回吐率；
- 退出后5日继续上涨的过早卖出率；
- 结构破位后继续下跌的风险规避率；
- 按市场环境、板块状态、换手率/量比分箱后的稳定性；
- 阈值小幅变化时结果是否稳定，防止只命中一个最佳点。

## 5. 已有证据与当前缺口

现有183笔历史平仓第一阶段显示：短持仓总体较差，6–20日组相对更好；60笔最终亏损交易曾有至少5%的最大浮盈，说明利润回吐确实是主要问题之一；同时退出后既有继续上涨，也有继续下跌，说明单一卖点无法覆盖全部场景。

目前仓库中的第一阶段报告只有日线汇总结论，没有完整的逐笔14:45分钟路径、同期历史板块快照与逐笔资金数据。因此现在可以确认“应采用叠加框架”，但不能诚实地宣称某组量比、换手或回撤阈值已经得到统计验证。

| 阶段 | 交付物 | 通过条件 | 运行方式 |
|---|---|---|---|
| A：规则契约 | 本文档、字段字典、无未来数据约束 | 规则可程序化、无歧义 | 立即完成 |
| B：数据集 | 逐笔交易日线/分钟线、成交量、换手率、量比代理、当时可得市场数据 | 覆盖率和缺失率报告通过 | GitHub分批，可断点续跑 |

| D：影子运行 | 每日输出V1正式建议与V2影子建议，不影响下单 | 连续不少于5个交易日可审计 | 14:45自动运行 |
| E：生产升级 | 固化阈值和版本 | 用户确认且验收报告通过 | 独立提交启用 |
