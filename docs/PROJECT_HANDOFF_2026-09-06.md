## 系统主流程

1. 用户在Streamlit上传当日强势股。
2. 系统与主股票池按六位代码合并去重，依次执行25日、120日、250日研究及市场板块分析。
3. OpenAI基于程序化数据形成次日观察池和微信盘后报告；允许空结果。
4. 下一交易日14:40采样，14:45综合大盘、板块、技术、资金、基本面、事件面输出`TRADE / WAIT / REJECT`。
5. 实际持仓未卖出时不得重复推荐；推荐、观察和真实持仓是不同状态。
6. 推荐按D+3、D+5、D+10跟踪；推荐日收盘为锚点，止损触发不含推荐当日。
