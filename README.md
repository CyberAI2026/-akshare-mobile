# A股强势股二次启动研究系统 V5.3

一个适合手机浏览器操作的 Streamlit + AKShare 研究平台。系统围绕“强势股第一波后的整理成熟与二次启动”构建，遵守A股T+1真实执行约束。

## 功能
- 主池维护 → 150–200只一级池 → 30–40只研究池 → OpenAI盘后0–10只观察池 → 14:45尾盘0–2只确认
- 25日粗筛数据抓取
- 120日结构筛选数据抓取（含5日成交量比，可选主要指数）
- 250日生命周期筛选数据抓取
- 五大指数、市场宽度及180个记录日滚动上下文
- 同花顺概念/行业即时、3日、5日、10日、20日板块资金增强层
- 14:40–14:45实时快照、5分钟K、OpenAI尾盘确认和PushPlus微信通知
- 股票代码/名称强制校验
- 重复日期、OHLC逻辑、成交量/成交额异常检查
- Excel 自动导出

## 市场数据正式口径

- 上涨、下跌、平盘：由全市场逐股快照按涨跌幅正负直接计数。
- 涨停、跌停：直接使用东方财富公开涨停池和跌停池，并保存成分代码用于审计。
- 乐咕市场活跃度：只作为独立交叉QA，不覆盖正式值。
- 同花顺板块资金：只作为板块、题材、资金增强证据，不替代个股结构，也不能单独生成候选。
- 正式数据源失败时必须显式标记降级；不能把失败伪装为“0只”或正常结果。

固定MA距离、固定缩量比例、固定等待天数、固定市场宽度阈值、固定回撤区间和固定平台宽度/触碰次数均不是硬规则。

## 本地运行
```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器会打开本地页面。电脑与手机在同一局域网时，也可用电脑局域网IP从手机访问。

## 云端部署（推荐）
可部署到 Streamlit Community Cloud、Render、Railway 或自己的云服务器。

最简单的 Streamlit Community Cloud 流程：
1. 创建 GitHub 仓库，把 `app.py` 和 `requirements.txt` 上传。
2. 登录 Streamlit Community Cloud。
3. 选择该仓库，入口文件填 `app.py`。
4. 部署后会得到一个网页地址，手机直接打开即可。

## 重要说明
AKShare 的上游数据源可能变化或临时限制访问。工具已做输入与结果校验，但仍建议每次先查看“数据质量校验表”，确认无异常后再用于策略研究。
